# Badge artwork

The badge layout and styling are custom. The Claude, C++, Qt, LangChain, LangGraph, and Python icon paths come from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Brand names and logos belong to their respective owners. Terminal and database symbols are custom generic icons for Codex and SQL.
